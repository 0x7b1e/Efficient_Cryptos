# Funding Event Prompt：资金费率结算窗口

这是独立于普通 `next_30min` 因子的资金费率事件板块。

研究目标：使用当前时点及之前可观察到的 Binance 永续合约数据，预测从当前
bar 到该币下一次真实 `funding_time` 的市场中性超额收益。资金费率结算间隔
必须从数据中的 `funding_time` 推断；不要把所有币强行假设为固定 6 小时，因
为不同合约或历史阶段可能是 4、6、8 小时。

允许重点研究：

- 当前资金费率的绝对水平、符号和横截面排名；
- 最近一次资金费率变化 `funding_rate[t] - funding_rate[t-1]`；
- 资金费率变化的加速度、持续性、滚动 z-score 和横截面异常度；
- 资金费率与收益、成交量、主动买入代理、持仓/多空比变化之间的背离；
- 高资金费率下价格动量衰减、低资金费率下空头拥挤后的反转；
- 资金费率信号与流动性、波动率和交易成本的交互。

严格禁止：

- 使用当前时点之后的 `funding_rate`、`funding_time` 或未来价格；
- 将下一次资金费率值、下一次结算时间或事件后的收益放入因子输入；
- 用固定的 6 小时 `shift(-n)` 代替真实事件标签；
- 把资金费率的支付成本误当作预测标签本身；标签是价格收益的横截面超额，
  资金费率支付只在交易回测成本阶段单独计入。

每个候选必须说明：

1. 使用的资金费率信息在 t 时刻如何可得；
2. 因子对下一次结算前收益的经济机制；
3. 事件间隔变化时为什么仍然有效；
4. 交易成本、换手、资金费率支付和事件临近流动性变化的风险。

因子代码只能使用当前输入行已有的 `funding_rate`、OHLCV 和已下载的持仓字段，
按 `symbol` 独立滚动，并返回与输入行完全对齐的 Series。预测目标固定填写：
`next_funding_event_excess_return`。
