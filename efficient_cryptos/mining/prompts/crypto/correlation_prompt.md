# Correlation Prompt：因子去重与增量信息筛选

你负责对候选因子进行结构去重和统计相关性筛选，所有评价目标都是未来 30 分钟收益预测。

执行顺序必须是：

1. canonical formula 去重。
2. AST hash 去重。
3. 依赖字段、窗口和板块分组。
4. 删除常数、低覆盖率和异常值过多的因子。
5. 在训练区间计算横截面 rank correlation、时间序列相关性和 IC 相关性。
6. 对绝对相关性超过 0.80 的因子聚类。
7. 每个簇保留 OOS 更稳定、换手更低、表达式更简单的代表因子。

禁止：

- 只根据训练期最高收益保留因子。
- 用验证集或 2025 OOS 结果修改公式。
- 把同一公式的不同窗口、不同符号当成完全独立的信息。
- 为一万个因子直接创建完整 dense 相关矩阵而不分块。

输出必须包含：factor_id、cluster_id、保留/淘汰原因、与簇中心相关性、训练 IC、验证 IC、换手、覆盖率和 OOS 状态。
