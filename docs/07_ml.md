# 07 ML models

Install first: `pip install -e ".[ml]"` (torch, tensorboard, lightgbm).
The neural network models (`resnet`, `gru`, `mlp`) prefer CUDA or Apple MPS; `--device auto` falls back to CPU when there is no GPU. `lgbm` is a separate tree-model branch.

## Feature and label cache

Features are built in `efficient_cryptos/features/frame.py` (no torch dependency): 1m klines are resampled to 30m, then derived features are computed — returns, volume, taker buy/sell, volatility, funding, positioning — along with beta and correlation to the market. All derived features are z-scored within each timestamp cross-section.

The cache has two layers (`efficient_cryptos/features/cache.py`):

```text
data/features/base_30m_d180_<hash>.parquet       Feature layer: independent of model, loss, seq_len and horizon
data/features/label_30m_h1_d180_<hash>.parquet   Label layer: stores only target and raw_target
```

```bash
python scripts/07_ml/build_feature_cache.py --data-dir data --symbols $SYMBOLS --interval 30m --days 180 --horizon 1
python scripts/07_ml/build_feature_cache.py --data-dir data --symbols $SYMBOLS --interval 30m --days 180 --horizon 4   # only builds a new label layer
```

The cache metadata records signatures of the source parquet files: when raw data is updated, the corresponding cache is invalidated automatically; `--rebuild-cache` forces a rebuild.

## Using selected factors as model features

```bash
# 1. Export predictions of the selected factors for the training and test periods (see 03)
python scripts/02_mining/extract_selected_factor_records.py --selected-dir factor_0_200 \
  --factor-jsonl outputs/crypto_factors.jsonl --out-jsonl outputs/selected.jsonl
python -u scripts/03_backtest/export_factor_predictions.py --factor-jsonl outputs/selected.jsonl ... \
  --train-start 2024-01-01 --train-end 2025-12-31 --out-dir outputs/ml_pred_train
python -u scripts/03_backtest/export_factor_predictions.py --factor-jsonl outputs/selected.jsonl ... \
  --train-start 2026-01-01 --train-end 2026-10-01 --out-dir outputs/ml_pred_test

# 2. Merge into one wide table; one column factor__<id> per factor, z-scored per cross-section
python scripts/07_ml/build_selected_factor_cache.py \
  --selected-dir factor_0_200 --prediction-dir outputs/ml_pred_train --prediction-dir outputs/ml_pred_test \
  --transform cs_zscore --out data/features/selected_factors_30m.parquet
```

Do not use `--allow-missing` for production caches. Missing factors should be exported for both the training and test periods, rather than silently becoming an all-zero feature column.

## Training

```bash
python -u scripts/07_ml/train_crypto_t1.py \
  --model resnet --loss mse_ic_spread \
  --data-dir data --symbols $SYMBOLS --interval 30m --horizon 1 --days 1100 --seq-len 48 \
  --factor-cache data/features/selected_factors_30m.parquet \
  --train-start 2024-01-01 --train-end 2025-09-30 \
  --validation-start 2025-10-01 --validation-end 2025-12-31 \
  --test-start 2026-01-01 --test-end 2026-10-01 \
  --allow-missing-positioning --layered-cache --min-symbols 8 --max-features 192 \
  --hidden-dim 128 --resnet-blocks 3 --dropout 0.1 --epochs 30 --patience 6 --device cuda \
  --epoch-metrics train,test --metrics-every 1 \
  --run-dir runs/resnet_selected --output-dir outputs/resnet_selected

tensorboard --logdir runs --host 0.0.0.0 --port 6006
```

- **Models**: `resnet gru mlp lgbm`; there are also architecture options such as attention, tlob and moe — see `--help`.
- **Labels**: `--label-mode horizon|utc_close|funding_event`.
- **Early stopping and checkpoint selection**: based only on validation-period RankIC. Test-period metrics are shown every epoch but never take part in selection.
- **Metrics in TensorBoard**: `train/ic`, `train/rank_ic`, `train/icir`, `validation/*`, `test/*`.
- **Outputs**: `best_model.pt` (`model.txt` for lgbm), `features.json`, `test_predictions.parquet`, `metrics.json`.

## Live trading

```bash
python scripts/06_live/run_live.py --ml-model outputs/resnet_selected --ml-k-long 2 --ml-m-short 2 \
  --symbols $SYMBOLS --rebalance-hours 4 --poll-seconds 60 --output outputs/ml_dry_run --network mainnet
```

The model fetches the historical klines it needs and selects k longs and m shorts. As with other signal sources, the selected target positions pass through the risk engine and exchange-side protections before orders are placed (see 06).
